# RadheSweets

Official Radhe Sweets Confectionery Shop Management Suite. Streamlined Point of Sale (POS), real-time inventory, customer orders, and analytics.

## Features
- **Instant POS Counter Billing**: Fast touch and keyboard enabled billing with discount options and multi-payment support.
- **Real-Time Inventory & Stock Adjustment**: Automated low stock alerts and recipe tracking.
- **Order Management & Thermal Receipts**: Order history, status tracking, and 80mm thermal receipt printing.
- **Responsive Design**: Optimized for desktop counter terminals, tablets, and mobile devices.

## Tech Stack
- Vanilla JavaScript & HTML5
- Tailwind CSS
- Vite
- Firebase

## Getting Started
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
